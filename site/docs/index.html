快速开始

十分钟跑通第一条渗透测试命令

需要 Python 3.10+。全部操作在你自己的机器上完成，模型端点由你提供。

1. 安装

pip install vulnclaw              # 含 CLI
pip install 'vulnclaw[web]'       # 需要本地 Web 操作台时

2. 配置模型

任选一个 OpenAI 兼容提供商，或指向你自己的端点。

vulnclaw config provider minimax        # openai / anthropic / deepseek / zhipu / moonshot / qwen / ollama ...
vulnclaw config set llm.base_url https://your-endpoint.example.com/v1
vulnclaw config set llm.model your-model-name
vulnclaw config set llm.api_key sk-your-key-here

配置与产物默认落在 ~/.vulnclaw（可用 VULNCLAW_CONFIG_DIR 覆盖）。

3. 跑第一条命令

vulnclaw recon https://example.com      # 只做信息收集
vulnclaw scan  https://example.com      # 漏洞扫描阶段
vulnclaw solve https://example.com --goal "确认是否存在未授权访问"
example.com 是文档保留域，请替换成你已获得授权的目标。

4. 本地 Web 操作台

vulnclaw web                # 默认 http://127.0.0.1:7788
vulnclaw web --port 8080    # 自定义端口

启动后终端会打印带 ?token= 的一次性链接，打开即完成本机会话鉴权。 操作台提供任务编排、运行详情、发现处置、报告中心、集成与定时任务。

5. 常用命令

命令 用途
vulnclaw run <target>一键全流程（默认 solve 引擎）
vulnclaw recon <target>仅信息收集，不利用
vulnclaw scan <target> --ports 80,443漏洞扫描阶段
vulnclaw exploit <target> --cve CVE-2024-1234漏洞利用阶段
vulnclaw report <session.json>从会话生成报告
vulnclaw report example.com --target --template executive按模板从目标状态生成报告（pentest / executive / ctf）
vulnclaw plugins list --stage discovery列出漏洞检测插件
vulnclaw code scan ./src --format sarif本地源码安全扫描
vulnclaw gc --older-than 30d --dry-run清理历史数据（先预演）

遇到问题

先跑 vulnclaw doctor 检查依赖与模型连通性；完整参数见仓库 README， 问题与建议走 GitHub Issues。
