VulnClaw
快速开始 GitHub PyPI English

AI Pentesting Agent

AI 驱动的自动化渗透测试工具，本地跑完整个流程

输入一句自然语言，VulnClaw 自动走完信息收集、漏洞发现、漏洞利用与报告生成。 LLM Agent + MCP 工具链 + 可选 Skill 参考资料，兼容 OpenAI / Anthropic / MiniMax / DeepSeek 等 OpenAI 兼容模型。

快速开始 查看源码 
pip install vulnclaw
vulnclaw web    # 打开本地操作台 http://127.0.0.1:7788

三条核心能力

不依赖云端面板，不把目标数据上传到第三方：模型调用由你配置，产物落在本机。

自然语言驱动全流程

一句话下达目标，Agent 分轮推进信息收集、漏洞发现、漏洞利用与报告生成，每轮事件与产物可回溯。

本地优先 + MCP 工具链

单机运行，任务状态与报告存在本机；通过 MCP 接入外部工具，插件按阶段与权限白名单加载。

结构化报告自动化

报告中心支持 Markdown / HTML / PDF / SARIF / JSON，模板可选渗透测试、执行摘要、CTF，可投递到 webhook / Jira / DefectDojo。

适合谁用

授权的渗透测试

把重复的侦察与已知漏洞验证交给 Agent，人工专注在判断与利用链设计。

CTF 与安全教学

可复现的分轮执行过程，适合作为教学与演练的执行底座。

红队自动化

定时任务 + 集成投递，把周期性检查与工单流转串成一条链路。

安全边界

VulnClaw 只用于已获得授权的渗透测试、CTF 竞赛与安全教学。 项目内置范围与动作边界（host / port / path / action 白名单与黑名单），越界动作会被拦截并记录。 未授权使用可能违反法律，风险由使用者承担。
